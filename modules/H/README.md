# Module H — Take-home workshop kit

## Purpose

Give participants a small, reusable starting kit for their own study. The kit
will pair blank templates with the completed pneumonia example so each item has
both an explanation and a concrete reference.

## Kit contents planned here

- Participant causal-roadmap worksheet
- Completed pneumonia roadmap
- Audit-log template
- Causal-diagram starter
- Simulated data and data dictionary
- Reproducible TMLE script
- Diagnostics and results summary
- Workshop slide deck

**Status:** Workshop-kit home ready; files will be added as they are finalized.
